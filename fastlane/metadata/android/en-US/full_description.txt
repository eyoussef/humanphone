HumanPhone puts a language model in charge of your phone. It is a chat client that can also read the screen and tap, type, scroll and navigate on your behalf, exactly like a person using the phone.

Two surfaces, one app:

* Chat: streaming conversations with image and file attachments, and replies read out loud with the
on-device text-to-speech voice (any installed voice engine — you pick it in Settings), or with an
API voice from an OpenAI-compatible /audio/speech
endpoint (OpenAI, Groq, a local server) when you choose one in Settings. From Settings you can
also install the on-device voice data, see whether the phone's recogniser is available, open the
voice input settings to install or switch one, and test both speech features without leaving the app.
* Operator: enable the HumanPhone accessibility service and hand a typed task to an agent loop that reads the visible screen and performs real taps, text entry, scrolling and app navigation until the task is done. Every step is shown live, and a run can be cancelled at any time. Auto mode goes further: new notifications are watched and answered on your behalf when a person actually needs a reply, while promotions, newsletters and one-time codes are skipped.

There is no HumanPhone account, no vendor backend and no telemetry. The app only talks to the model endpoints you configure: a local Ollama server, OpenRouter, or any OpenAI-compatible base URL with /chat/completions. An optional OpenAI-compatible /audio/transcriptions endpoint (for example Whisper) turns dictation into text; without it the phone's own speech recogniser is used.

The operator has tools for reading the screen, tapping a node or text, typing and clearing text, scrolling, back/home/recents/notifications, launching apps, opening URLs, placing calls, composing texts, looking up contacts, creating alarms, opening system settings pages, waiting for text to appear, remembering small facts between runs, speaking out loud and finishing with a summary.

The interface ships in English, العربية, Français, Español, Português and हिन्दी (per-app language, Android 13 or newer).

Nothing leaves the device except the requests to those endpoints: screen contents are only sent when you turn on screenshot sending, and conversations are stored locally.

Requires Android 11 or newer. For the operator, Android also needs the HumanPhone accessibility service enabled (Settings, Apps, HumanPhone, Restricted settings).

Heads-up: the operator performs real actions on your device - taps, typing, calls, texts, alarms. What it does depends entirely on the model you connect and what you ask it to do, and models make mistakes. Watch each run live, start with simple tasks, and use it on your own responsibility.
